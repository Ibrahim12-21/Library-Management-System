# 📚 Library Management System

A Python-based **Library Management System** built using **Object-Oriented Programming (OOP)**. This project provides a simple console-based system for managing books, library members, borrowing, returning, and book availability.

## 🚀 Features

* 📖 Add new books
* 📚 View all books
* 🔍 Search books by title, author, or ID
* 👤 Register new library members
* 👥 View all members
* 📥 Borrow books
* 📤 Return books
* 🗑️ Remove books
* ❌ Remove members
* ✅ Track book availability
* ⚠️ Prevent borrowing unavailable books
* 🔒 Prevent removing borrowed books or members with borrowed books

## 🛠️ Technologies Used

* **Python 3**
* **Object-Oriented Programming (OOP)**

## 🧠 OOP Concepts Practiced

This project was developed to apply Python OOP concepts in a real-world application.

* Classes and Objects
* Constructors (`__init__`)
* Instance Attributes
* Methods

* Lists and Loops
* Conditional Statements

The main purpose of this project is to strengthen **Python programming and Object-Oriented Programming skills** by building a practical real-world application.
